# Domain-specific architecture



## wikipedia [Domain-specific architecture](https://en.wikipedia.org/wiki/Domain-specific_architecture)

A **domain-specific architecture (DSA)** is a programmable [computer architecture](https://en.wikipedia.org/wiki/Computer_architecture "Computer architecture") specifically tailored to operate very efficiently within the confines of a given application domain. The term is often used in contrast to general-purpose architectures, such as [CPUs](https://en.wikipedia.org/wiki/CPU "CPU"), that are designed to operate on any [computer program](https://en.wikipedia.org/wiki/Computer_program).
