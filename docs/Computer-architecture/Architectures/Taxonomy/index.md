## **Single instruction, multiple threads** (**SIMT**)

### wikipedia [Single instruction, multiple threads](https://en.wikipedia.org/wiki/Single_instruction,_multiple_threads)

**Single instruction, multiple threads** (**SIMT**) is an execution model used in [parallel computing](https://en.wikipedia.org/wiki/Parallel_computing "Parallel computing") where a single central "control unit" broadcasts an instruction to multiple "processing units" for them to all *optionally* perform simultaneous synchronous and fully-independent parallel execution of that one instruction. Each PU has its own independent data and address registers, its own independent memory, but no PU in the array has a [program counter](https://en.wikipedia.org/wiki/Program_counter "Program counter"). In [Flynn's 1972 taxonomy](https://en.wikipedia.org/wiki/Flynn's_1972_taxonomy "Flynn's 1972 taxonomy") this arrangement is a variation of [SIMD](https://en.wikipedia.org/wiki/SIMD "SIMD") termed an **array processor**.
